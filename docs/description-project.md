Este proyecto resuelve la falta de trazabilidad en la gestión y aforo de centros deportivos, ofreciendo a administradores una plataforma para optimizar la toma de decisiones. El sistema automatiza el registro de usuarios, monitorea horas pico y genera reportes semanales sobre el uso de las instalaciones. Está desarrollado con un stack moderno que combina Next.js y Tailwind CSS en el frontend, junto con un backend optimizado y base de datos relacional. Actualmente, la aplicación cuenta con los módulos principales funcionales, pruebas locales superadas y se encuentra lista para su fase de despliegue
